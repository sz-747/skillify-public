# Example workspace supplement

This file contains fictional relative locations. It does not define real credentials or authorise any action.

- Put project-specific skills in the current project's `.agents/skills/` directory.
- Check the project's existing capability catalogue before creating a new entry.
- Expose one `SKILL.md` per capability; keep helper references internal.
- Record source URL, revision and adaptation notes in the project's private notes directory.
- Run the destination's documented link, discovery and package checks before calling installation complete.
- Keep account selection, real paths, credentials and user data in private workspace configuration.
- Do not initialise a repository, publish it or migrate other skills unless the current request includes that work.

Replace these choices with the receiving workspace's actual rules and store the result privately.
